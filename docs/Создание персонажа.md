1. **Брось по 3d6 для каждой из трёх пар характеристик:
	- Сила и Интеллект
	- Телосложение и Ловкость
	- Харизма и Мудрость
2. **Выбери класс** (см. [Классы]({% link docs/Классы.md %}))
3. **Брось и запиши начальные Пункты Здоровья** (ПЗ): они равны **6 + d6**. 
4. **Брось 3d6 на начальное снаряжение:**

| 3d6    | Снаряжение                                                                       |
| ------ | -------------------------------------------------------------------------------- |
| **3**  | Рваная одежда. Больше ничего.                                                    |
| **4**  | Лёгкое оружие (d4).                                                              |
| **5**  | Лёгкое оружие (d4), факел ∆6                                                     |
| **6**  | Лёгкое оружие (d4), лёгкая Броня (КБ 1).                                         |
| **7**  | Лёгкое оружие (d4), лёгкая броня (КБ 1), верёвка (50 футов).                     |
| **8**  | Среднее оружие (d6), лёгкая Броня (КБ 1).                                        |
| **9**  | Среднее оружие (d6), лёгкая Броня (КБ 1), факел ∆6                               |
| **10** | Среднее оружие (d6), лёгкая Броня (КБ 1), верёвка (50 футов).                    |
| **11** | Среднее оружие (d6), лёгкая Броня (КБ 1), паёк ∆4                                |
| **12** | Среднее оружие (d6), лёгкая Броня (КБ 1), щит (+1 КБ).                           |
| **13** | Тяжёлое оружие (d8), лёгкая Броня (КБ 1), факел ∆6                               |
| **14** | Тяжёлое оружие (d8), средняя броня (КБ 2), верёвка (50 футов).                   |
| **15** | Тяжёлое оружие (d8), средняя броня (КБ 2), паёк ∆4                               |
| **16** | Тяжёлое оружие (d8), средняя броня (КБ 2), лечебный отвар ∆4)                    |
| **17** | Тяжёлое оружие (d8), тяжёлая броня (КБ 3), лечебный отвар ∆6, верёвка (50 футов) |
| **18** | Тяжёлое оружие (d8), тяжёлая броня (КБ 3), лечебный отвар ∆6, паёк ∆4, факел ∆6  |
5. **Выбери мировоззрение**: Законное, Нейтральное или Хаотичное. 
6. **Придумай себе имя.**
